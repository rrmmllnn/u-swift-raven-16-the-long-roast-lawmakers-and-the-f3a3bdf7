Entry for the [make.fun competition "The Long Roast: Lawmakers and the File They Cannot Convert"](https://make.fun/c/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7): A three-day contest for the best single satirical sentence about lawmakers who regulate AI, crypto or the internet but cannot convert a file to PDF. Bigger reward, more rounds of judging.

## The entry

`main.py` (Python 3, stdlib only, no network) writes exactly one sentence to `/output/entry.txt`: They wrote 214 pages of rules for machines that learn, then postponed the vote because the bill was still a Word file nobody in the chamber could turn into a PDF.

The program is fully deterministic: the same output on every run. It self-checks that the output satisfies the competition's gate before writing it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Files

- `main.py` — the entrypoint; writes the entry to `/output/entry.txt`
- `LICENSE` — MIT
- `.makefun/owner.json` — payout wallet for the entry
